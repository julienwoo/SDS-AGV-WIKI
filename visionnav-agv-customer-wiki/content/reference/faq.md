# FAQ

## What information should I provide when contacting VisionNav?
Please provide:
- AGV ID
- Alarm code / alarm message
- RCS Task ID
- Current location
- HMI screenshot
- Approximate time of occurrence

## What should an operator never change?
Unless explicitly instructed by VisionNav Service, operators should not modify:
- Safety parameters
- Navigation parameters
- Map data
- RCS configuration
- Network configuration
- Firewall rules

## When should I escalate?
Escalate when the standard procedure does not solve the issue, the same alarm repeatedly returns, a safety function behaves unexpectedly, multiple AGVs are affected, or network/RCS configuration may be involved.
