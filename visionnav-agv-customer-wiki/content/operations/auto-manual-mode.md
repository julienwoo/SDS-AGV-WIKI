# Auto / Manual Mode

**Access level:** Operator · Level 1

## Auto Mode
Use Auto Mode for normal automatic operation under RCS control.

Before selecting Auto Mode:
- Safety conditions are normal.
- No active alarm prevents automatic operation.
- The operating area is clear.
- The AGV is Ready.

## Manual Mode
Use Manual Mode only for approved manual operation or service procedures.

Before returning to Auto Mode:
1. Stop manual movement.
2. Confirm the AGV is in a safe state.
3. Release the manual control device according to the project procedure.
4. Confirm safety conditions.
5. Select Auto Mode.
6. Confirm the AGV becomes Ready / Online as applicable.
