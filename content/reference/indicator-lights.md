## Overview

Most AGVs use a tower/beacon light to show status at a glance from a distance. Exact colors and patterns can vary slightly by AGV model — always confirm against your project's SOP.

| Light | Pattern | Meaning |
|---|---|---|
| 🟢 Green | Solid | Auto mode, Ready/Running normally |
| 🟢 Green | Slow blink | Idle, waiting for task |
| 🔵 Blue | Solid | Manual mode active |
| 🟡 Yellow | Solid | Charging |
| 🟡 Yellow | Blinking | Warning — degraded state, not stopped |
| 🔴 Red | Solid | Fault — AGV stopped, alarm active |
| 🔴 Red | Fast blink | Emergency stop active |
| ⚪ Off | — | AGV is powered off |

## Sound Signals (if equipped)

| Sound | Meaning |
|---|---|
| Short beep on start | AGV is about to move (Auto mode) |
| Continuous alarm tone | Fault / E-Stop active |
| Double beep | Task completed |

## If Lights Don't Match This Table

If your AGV's indicator behavior does not match this reference, note the AGV ID and model, and check with your supervisor or VisionNav Service — this reference may need a project-specific update.
