## What it does

The Reset button clears the AGV's current error code and abnormal status marks. In Automatic mode it's also used to restart the system if it freezes or gets stuck.

## When to use it

After you've already dealt with what caused the alarm — obstacle cleared, E-Stop released, laser path clear, mode corrected. Reset clears the fault flag; it doesn't fix the underlying cause. This is the same single procedure whether you're clearing an alarm that came up in Automatic mode or resuming after working on the AGV in Manual mode — there's no separate "manual reset" and "automatic reset."

## Steps

1. Confirm the condition that caused the alarm is actually resolved.
2. Press **Reset** on the AGV control panel.
3. Press **Start** to resume (Automatic mode), or confirm the tri-color light and RCS status return to normal.

## Caution

Don't press Reset repeatedly as a substitute for diagnosis. If the same alarm re-triggers immediately after Reset, the underlying cause is still present — stop and check the specific troubleshooting article for that alarm instead of resetting again.
